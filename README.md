# 💣 MinesCipher v2 — Minesweeper Feistel Network (MFN)

> **현대암호학 조별과제 프로젝트**  
> **프로젝트명**: 지뢰찾기 인접 숫자 계산의 일방향성을 활용한 Feistel 구조 대칭키 블록 암호 설계 및 구현

---

## 📌 1. 프로젝트 개요

지뢰찾기(Minesweeper) 게임은 **"지뢰를 맵에 배치하고 인접 숫자를 계산하는 것은 빠르지만, 숫자 맵만 보고 지뢰의 위치를 역추론하는 것은 극도로 어렵다(NP-완전 문제)"** 는 특성을 가집니다.  
본 프로젝트는 이 **인접 숫자 계산(비가역적 일방향 함수)** 을 Feistel 라운드 함수의 비선형 변환으로 사용하는 대칭키 블록 암호 **`MinesCipher v2 (MFN)`** 를 제안하고 구현했습니다.

Feistel 구조를 채택했기 때문에 라운드 함수 F 자체는 역연산이 불가능해도, 암호 전체는 완전히 가역적입니다.

### 사양 요약

| 항목 | 값 |
| :--- | :--- |
| **구조** | Balanced Feistel Network |
| **블록 크기** | 128비트 (16바이트) — 좌/우 각 64비트 |
| **키 길이** | 임의 길이 (SHA-256으로 256비트 마스터 시드로 정규화) |
| **라운드 수** | 16 |
| **라운드 키** | 64비트 × 16개 |
| **운용 모드** | CBC + PKCS#7 패딩 (랜덤 IV를 암호문 앞에 부착) |

## 🌟 2. 기존 암호(AES 등)와의 차별성 및 독창성

| 비교 항목 | 기존 블록 암호 (예: AES-128) | **MinesCipher v2** |
| :--- | :--- | :--- |
| **전체 구조** | SPN (모든 단계가 가역이어야 함) | **Feistel** (라운드 함수가 비가역이어도 됨) |
| **Confusion 원천** | 고정된 단일 S-Box (치환 테이블) | **8×8 그리드의 지뢰찾기 인접 숫자 계산** — 8개 이웃의 정수 합에서 생기는 올림(carry)이 GF(2) 위의 비선형성 제공 |
| **Diffusion** | ShiftRows + MixColumns | **2D 인접성**(1비트가 주변 최대 9셀의 출력에 영향) + **XOR 폴딩** + Feistel 좌우 교차 |
| **Key Schedule** | 대수적 연산 (Rcon 상수 + S-Box + 회전) | **BFS 지뢰찾기 연쇄 오픈 탐색 순서** → HMAC-SHA256으로 라운드 키 파생 |
| **라운드 상수** | Rcon | `SHA-256("MinesCipher_v2_RC" ∥ r)` 상위 64비트 (Slide Attack 방어, 퇴화 입력 방지) |
| **2D 공간성 활용** | 1차원 배열을 편의상 4×4 행렬로 표현 | 셀 간의 **물리적 인접성(Adjacency)** 자체가 출력 값 결정 |

## 🏗️ 3. 암호 알고리즘 구조도

### 3.1 전체 구조 (16라운드 Feistel)

```
            평문 128비트
        ┌────────┴────────┐
      L₀ (64)           R₀ (64)
        │                 │
        ▼                 │
       (⊕)◀──── F ◀───────┤◀── K_r, RC_r
        │                 │
        └───────╲ ╱───────┘
                 ╳              × 16 라운드
        ┌───────╱ ╲───────┐      L_{r+1} = R_r
        ▼                 ▼      R_{r+1} = L_r ⊕ F(R_r, K_r, RC_r)
       ...               ...
        └────────┬────────┘
          최종 스왑 (R₁₆ ∥ L₁₆)
                 ▼
            암호문 128비트
```

복호화는 같은 구조에 라운드 키를 **역순**으로 적용합니다.

### 3.2 라운드 함수 F(R, K_r, RC_r)

```
              R (64비트)
                  │
                  ▼
    ┌───────────────────────────┐
    │  Step 1: 키 혼합           │   X = R ⊕ K_r ⊕ RC_r
    └─────────────┬─────────────┘
                  ▼
    ┌───────────────────────────┐
    │  Step 2: 그리드 변환        │   64비트 → 8×8 이진 그리드
    │                           │   (비트 1 = 💣 지뢰, 비트 0 = 안전)
    └─────────────┬─────────────┘
                  ▼
    ┌───────────────────────────┐
    │  Step 3: 인접 숫자 계산     │ ◀── [비선형 변환 / Confusion]
    │                           │   지뢰 셀 → 0xF
    │                           │   안전 셀 → 이웃 지뢰 수 (0~8)
    └─────────────┬─────────────┘
                  ▼
    ┌───────────────────────────┐
    │  Step 4: XOR 폴딩          │   64 nibble(256비트) → 32바이트 패킹
    │                           │   → 8바이트 청크 4개를 XOR → 64비트
    └─────────────┬─────────────┘
                  ▼
           F 출력 (64비트)
```

### 3.3 키 스케줄

```
키 (임의 길이) ──SHA-256──▶ 마스터 시드 (256비트)
                              │
                              ▼
          시드 기반 셔플로 8×8 보드에 지뢰 10개 배치
                              │
                              ▼
          인접 숫자 맵 계산 → 시드 마지막 2바이트로 시작 셀 결정
                              │
                              ▼
          BFS 연쇄 오픈 시뮬레이션 (빈 칸이면 주변 8칸 확장)
          → 64칸 전체의 방문 순서(visit_order) 확정
                              │
                              ▼
          K_r = HMAC-SHA256(시드, r ∥ visit_order)[:8]   (r = 0..15)
```

## 📊 4. 실험 결과 (보안성 검증)

아래 수치는 `python mines_cipher_v2.py` 실행 결과입니다.

### ① 완전 가역성 (Invertibility)
- 단일 블록: $D_K(E_K(P)) = P$ 확인
- 랜덤 키(8~32바이트) · 랜덤 블록 **1,000회 테스트 → 1,000/1,000 통과**
- CBC 모드 + PKCS#7 패딩으로 한글 메시지(110바이트 → IV 포함 128바이트) 정상 복원

### ② Avalanche Effect (눈사태 효과)
- 고정 평문에서 128개 비트 위치를 하나씩 반전시키며 `encrypt_block()` 암호문 변화율 측정 (CBC의 랜덤 IV 영향 배제)

| 통계 | 변화율 |
| :--- | :--- |
| **평균** | **49.43%** |
| 최소 | 36.72% |
| 최대 | 61.72% |
| 이상적 목표 | 50.00% |

### ③ 키 민감도 (Key Sensitivity)
- 키의 1비트만 반전 → 암호문 **128비트 중 70비트 변경 (54.69%)**

## 🚀 5. 실행 방법

별도의 외부 라이브러리(pip 설치) 없이 표준 Python 3으로 즉시 실행 가능합니다.

```bash
python mines_cipher_v2.py
```

### 실행 시 출력되는 데모:
1. **Demo 1**: 단일 블록 암복호화 가역성 검증 + 랜덤 1,000회 테스트
2. **Demo 2**: CBC 모드 한글 메시지 암복호화 정합성 검증
3. **Demo 3**: 평문 1비트 플립에 따른 Avalanche 확산율 측정 (128비트 전체)
4. **Demo 4**: 키 1비트 변경에 따른 키 민감도 측정
5. **Demo 5**: 라운드 함수 F 1스텝 시각화 (이진 그리드 → 인접 숫자 맵 → XOR 폴딩)

### 코드에서 사용하기

```python
from mines_cipher_v2 import MinesCipherV2

cipher = MinesCipherV2(b'SuperSecretKey123!')

ct = cipher.encrypt("안녕하세요".encode('utf-8'))   # IV ∥ C₁ ∥ C₂ ∥ ...
pt = cipher.decrypt(ct).decode('utf-8')

# 단일 블록 (정확히 16바이트)
block_ct = cipher.encrypt_block(bytes(range(16)))
block_pt = cipher.decrypt_block(block_ct)
```

> 이전 버전(SPN 스타일, MineRowShift/MineColShift 기반)은 [mines_cipher.py](mines_cipher.py)에 남아 있습니다.
