# 💣 MinesCipher (지뢰찾기 기반 독창적 블록 암호)

> **현대암호학 조별과제 프로젝트**  
> **프로젝트명**: 지뢰찾기 게임의 NP-완전성 및 일방향성을 활용한 대칭키 블록 암호 설계 및 구현

---

## 📌 1. 프로젝트 개요

지뢰찾기(Minesweeper) 게임은 **"지뢰를 맵에 배치하는 것은 직관적이고 빠르지만, 숫자 맵만 보고 지뢰의 위치를 역추론하는 것은 극도로 어렵다(NP-완전 문제)"** 는 특성을 가집니다.  
본 프로젝트는 이러한 지뢰찾기의 수학적·게임적 메커니즘을 블록 암호의 핵심 설계 원칙인 **Confusion(혼돈)** 과 **Diffusion(확산)** 에 융합하여 독창적인 대칭키 블록 암호 **`MinesCipher`** 를 제안하고 구현했습니다.

---

## 🌟 2. 기존 암호(AES 등)와의 차별성 및 독창성

| 비교 항목 | 기존 블록 암호 (예: AES-128) | **MinesCipher** |
| :--- | :--- | :--- |
| **Confusion 원천** | 고정된 단일 S-Box (치환 테이블) | **키-의존적 2D 지뢰 인접 숫자 맵** (키마다 고유한 치환 환경) |
| **Diffusion (가로)** | ShiftRows (행마다 0, 1, 2, 3칸 **고정** 시프트) | **MineRowShift** (해당 행의 **지뢰 개수**에 따른 **동적** 시프트) |
| **Diffusion (세로)** | MixColumns (고정된 다항식 행렬 곱연산) | **MineColShift** (해당 열의 **지뢰 개수**에 따른 **동적** 시프트) |
| **Key Schedule** | 대수적 연산 (Rcon 상수 + S-Box + 회전) | **BFS 지뢰찾기 연쇄 오픈 탐색 순서** + **결정론적 맵 변형** |
| **2D 공간성 활용** | 1차원 배열을 편의상 4x4 행렬로 표현 | 셀 간의 **물리적 인접성(Adjacency)** 자체가 암호화 값 결정 |

## 🏗️ 3. 암호 알고리즘 구조도

### 1 라운드 변환 과정 (Round Function)

```
        입력 상태 (N × N Nibble Grid)
                      │
                      ▼
        ┌───────────────────────────┐
        │  Step 1: AddMineKey       │  ◀── [Confusion]
        │  (셀 ⊕ 인접숫자맵 ⊕ 서브키) │      지뢰 셀은 0xF로 전비트 반전
        └─────────────┬─────────────┘
                      │
                      ▼
        ┌───────────────────────────┐
        │  Step 2: MineRowShift     │  ◀── [Horizontal Diffusion]
        │  (행 지뢰 개수만큼 좌시프트)│      키에 따라 동적으로 달라지는 시프트량
        └─────────────┬─────────────┘
                      │
                      ▼
        ┌───────────────────────────┐
        │  Step 3: MineColShift     │  ◀── [Vertical Diffusion]
        │  (열 지뢰 개수만큼 하시프트)│      가로/세로 교차 확산 완성
        └─────────────┬─────────────┘
                      │
                      ▼
        ┌───────────────────────────┐
        │  Map Mutation (맵 변형)   │  ◀── [Round Key Evolution]
        │  (라운드마다 지뢰 위치 이동) │      Slide Attack 방어 및 Avalanche 극대화
        └───────────────────────────┘
```

## 📊 4. 실험 결과 (보안성 검증)

### ① 완전 가역성 (Invertibility)
- 평문 ↔ 암호문 ↔ 복호문 전 과정에서 무손실 원본 복원 확인 ($D_K(E_K(P)) = P$)
- CBC 모드 및 PKCS#7 패딩을 적용하여 긴 텍스트(한글/영문/바이너리) 정상 지원

### ② Avalanche Effect (눈사태 효과) 테스트
- 평문에서 **단 1비트(Bit)** 만 반전시켰을 때의 암호문 변화율 측정:
- **측정 결과**: `512비트 중 256비트 변경 (50.00%)` 달성
- 암호학적 이상치인 **50%에 완벽하게 수렴**하여 우수한 확산성 입증

```bash
python mines_cipher.py
```

### 실행 시 출력되는 데모:
1. **Demo 1**: 4×4 규격 명세서 기반 수동 1라운드 스텝별 연산 추적

3. **Demo 3**: 1비트 플립에 따른 Avalanche 확산율 측정

```
[1주차] 알고리즘 컨셉 수립, 수학적 모델링 및 명세서(Specification) 작성
   ↓
[2주차] Python 기반 코어 암복호화 엔진 및 CBC 운용 모드, BFS 키 스케줄 구현
   ↓
[3주차] 보안성 실험(Avalanche Effect, 빈도 분석) 및 성능 벤치마크, 시각화 도구
   ↓
[4주차] 팀 발표 자료(PPT) 제작, 최종 리허설 및 보고서 제출
```
