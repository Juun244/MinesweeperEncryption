# 💣 MineLock v3 — 지뢰찾기 규칙으로 만든 블록 암호

> **현대암호학 조별과제 프로젝트** · 2조 YSKL (손홍배 · 강인석 · 여태준 · 이채은)
> 지뢰찾기의 "주변 지뢰 수 세기"를 치환으로, 지뢰판의 행·열 회전을 전치로 사용한 SPN 대칭키 블록 암호

---

## 📌 1. 개요

MineLock v3는 128비트 블록을 **8행 × 16열 지뢰판**(1 = 지뢰, 0 = 빈칸)으로 보고, 매 라운드 판 전체를 바꾸는 **SPN 구조** 블록 암호입니다.

- **치환 (MineSub)**: 각 칸의 주변 지뢰 수를 세어 0·3·4·8이면 그 칸을 뒤집습니다.
- **전치 (MinePerm)**: 행과 열을 정해진 칸 수만큼 회전해 이웃했던 비트를 판 전체로 흩습니다.
- **키 스케줄**: 비밀키로 만든 첫 지뢰판에 같은 연산을 적용해 한 수씩 진화시키고, 각 단계의 판을 라운드 키로 씁니다.

1차 발표의 Feistel 설계(v2)에 대한 피드백("구조에 변화를", "치환·전치를 구체적으로")과 검토에서 지적된 약점(차분 경로, 키 스케줄 확산)을 반영해 확정한 설계입니다.

### 사양

| 항목 | 값 |
| :--- | :--- |
| **구조** | SPN (치환-전치 반복) |
| **블록 크기** | 128비트 = 8 × 16 지뢰판 (판의 위아래·좌우는 이어져 있어 모든 칸의 이웃이 8개) |
| **키** | 임의 길이 → SHA-256 앞 128비트 = 초기 지뢰판 B(0) |
| **라운드** | 16 × (⊕ K(r) → MineSub → MineSub → MinePerm), 마지막에 ⊕ K16 |
| **라운드 키** | K0 ~ K16, 17개 × 128비트 |
| **운용 모드** | CBC + PKCS#7 패딩 (랜덤 IV를 암호문 앞에 부착) |

## 🏗️ 2. 알고리즘 구조

### 2.1 MineSub (치환) — 지뢰찾기 규칙으로 칸 뒤집기

1. 칸을 (행 홀짝, 열 홀짝)으로 **4색 분할**합니다. 같은 색 칸끼리는 서로 이웃이 아닙니다.
2. 색 0 → 1 → 2 → 3 순서로, 해당 색의 각 칸에서 **주변 지뢰 수 c**를 셉니다.
3. **c ∈ {0, 3, 4, 8}이면 그 칸을 반전**합니다.

한 단계에서 바뀌는 칸의 이웃은 그 단계 동안 변하지 않으므로, 복호화는 같은 규칙을 색 3 → 0 역순으로 적용하면 됩니다. 규칙 {0, 3, 4, 8}은 가능한 512개 규칙 중 0/1 균형이면서 최대 선형 편향이 가장 작은(1/16) 것입니다. 라운드마다 MineSub를 **2번** 적용해 1비트 차분 경로의 확률을 낮췄습니다.

### 2.2 MinePerm (전치) — 행·열 회전

```
① 행 i를 오른쪽으로 (3i + 1)칸 회전   →  j' = (j + 3i + 1) mod 16
② 열 j'을 아래로 j'칸 회전              →  i' = (i + j') mod 8
```

### 2.3 키 스케줄 — 지뢰판 진화

```
Evolve(B) = MinePerm(MineSub(MineSub(B)))          (키 없는 라운드)
B(0)  = SHA-256(비밀키)의 앞 128비트                → K0
B(r)  = Evolve(Evolve(B(r-1))) ⊕ RC(r)             → K(r)   (r = 1 … 16)
RC(r) = SHA-256("MineLock_RC" ∥ r)의 앞 128비트
```

### 알려진 한계

- 1비트 차분 경로는 16라운드에서 충분히 낮지만, **여러 비트 차분 경로와 선형 경로는 아직 체계적으로 분석하지 않았습니다.**
- 키 스케줄은 되돌릴 수 있는 연산이라, 라운드 키 하나로 나머지 라운드 키를 복원할 수 있습니다 (AES-128과 같은 성질).
- 대수 차수와 적분 공격에 대한 분석은 하지 않았습니다.

> ⚠️ MineLock은 교육·연구 목적의 과제용 설계입니다. 실제 데이터 보호에 사용하지 마세요.

## 🚀 4. 실행 방법

별도의 외부 라이브러리 없이 표준 Python 3으로 실행할 수 있습니다.

```bash
python mines_cipher_v3.py                       # 데모: 가역성, CBC, 확산, 키 민감도, 라운드 1 시각화, 속도
python -m unittest test_mines_cipher_v3 -v      # 기준 구현과 비트 단위 비교 테스트
```

코드에서 사용하기:

```python
from mines_cipher_v3 import MinesCipherV3

cipher = MinesCipherV3(b"YSKL")
ct = cipher.encrypt("안녕하세요".encode("utf-8"))   # IV ∥ C₁ ∥ C₂ ∥ ...
pt = cipher.decrypt(ct).decode("utf-8")

block_ct = cipher.encrypt_block(bytes(range(16)))  # 단일 블록 (16바이트)
```

문서·그림 다시 만들기 (`tools/`):

```bash
python tools/trace_hello.py hello.json          # 설명서 5장 HELLO 예시 값
python tools/measure_v3.py measure.json         # 설명서 6장 검증 수치
python tools/make_flowcharts.py "docs/2차"      # 순서도 4종 (.drawio + .png, Pillow 필요)
node tools/make_doc.js out.docx hello.json measure.json "docs/2차"   # 설계 설명서 (npm docx 필요)
```
